### Sobre mí

- 🎓 Ingeniero Electrónico (Universidad del Norte) y estudiante de la **Maestría en Ciencia de Datos** en la Universidad Pontificia Bolivariana (UPB)
- 📊 Experiencia en el ciclo completo del dato: **ETL, limpieza, modelado y visualización** con Python, SQL y Power BI
- 🤖 Desarrollando mi tesis: un **agente de IA multiproveedor basado en LLM** con LangGraph y RAG
- 🌱 Profundizando en **MLOps** y despliegue de modelos en producción
- 💼 Abierto a oportunidades como **Analista o Científico de Datos**: remoto, Medellín, Bogotá o Barranquilla

### 🚀 Proyectos destacados

- **Agente de IA multiproveedor para software CMMS** *(tesis, en desarrollo)*: agente con LangGraph que gestiona órdenes de trabajo vía API REST, con fundamentación RAG, crítica en dos niveles y registro auditable de cada acción.
- **Red neuronal para asignación de auditores**: modelo para distribuir asesores SOC y PCI DSS según proyectos activos, especialidad y zona horaria, equilibrando la carga operativa.
- **ETL y migración de catálogo de precios**: migración desde hojas de cálculo a PostgreSQL (Supabase, Prisma) con limpieza, normalización e integración de una API de TRM.
